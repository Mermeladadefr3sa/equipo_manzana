# equipo_manzana
Este proyecto es una página web desarrollada con una plantilla gratuita de **Bootstrap**, con el objetivo de aplicar los conocimientos sobre estructura de proyectos web, control de versiones con GitHub, y personalización de interfaces web.  
El sitio fue modificado para incluir información original del equipo, colores personalizados y una sección adicional llamada **“Acerca del equipo”**.

# Propósito
El propósito de este proyecto es aprender a trabajar colaborativamente utilizando Git y GitHub, comprender la estructura de una plantilla Bootstrap y personalizarla para representar un proyecto propio de manera funcional, visualmente atractiva y organizada.
